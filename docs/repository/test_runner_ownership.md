# MATLAB test runner ownership and validation tiers

Last reviewed: 2026-07-15

This document is the maintained ownership contract for `tests/`. The
machine-readable companions are regenerated by `buildTestInventory` and
`buildTestOwnership`:

```text
analysis/test_inventory/test_inventory.csv
analysis/test_inventory/runner_edges.csv
analysis/test_inventory/test_runner_ownership.csv
```

## Ownership rules

- Every maintained test has exactly one direct canonical owner.
- Aggregate runners call focused owners rather than sibling tests.
- Repeated reachability through aggregates is intentional and is not duplicate
  direct ownership.
- Runtime tiers describe validation purpose; elapsed time is never a pass/fail
  threshold.
- Nine compatibility wrappers and standalone `run_main_gui_export_tests` remain
  public commands.

Current generated state: 106 tests, 42 runner implementations, 9 compatibility
wrappers, 3 helpers, 222 graph edges, 106 canonical owners, 0 manual-only tests,
0 unowned tests, 0 multiple canonical owners, 0 sibling direct overlaps, and 0
runner cycles.

## Public validation tiers

| Tier | Command | Static reach | Purpose |
| --- | --- | ---: | --- |
| quick contract | `run_quick_contract_tests` | 15 | paths, metadata, validation, imports, and pure helpers |
| quick smoke | `run_quick_smoke_tests` | 48 | quick contracts plus representative GUI, AE, and mRLFE execution |
| numerical regression | `run_numerical_regression_tests` | 14 | deterministic model and result-schema evidence |
| extended integration | `run_extended_integration_tests` | 44 | matrices, fitting recovery, consumers, and characterization |
| performance | `run_performance_and_benchmark_tests` | 2 | descriptive performance evidence |

`run_quick_smoke_tests` is the routine developer command. Characterization,
performance, the full execution-profile matrix, and broad fitting recovery stay
outside quick validation.

## Regeneration and integrity checks

```matlab
clear functions
rehash toolboxcache
startup

[inventory, edges] = buildTestInventory('WriteCsv', true);
ownership = buildTestOwnership('WriteCsv', true, 'ValidateActual', true);

assert(height(ownership) == 106)
assert(nnz(ownership.ManualOnly) == 0)
assert(all(strlength(ownership.CanonicalRunner) > 0))
```

The parser is static. Dynamic calls and MATLAB path resolution remain subject
to the limitations in `analysis/test_inventory/README.md`, so maintained quick
and focused runners must also be executed.
